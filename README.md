# Tia Rexine Portfolio

A personal portfolio built with Next.js App Router, React, TypeScript, and Tailwind CSS. The homepage features Rexine Spa Care and Free Space Therapy, with the uploaded mountain photograph as the hero backdrop.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy to Vercel

Import `makapiatia/tia-rexine-app` into Vercel and deploy with the default Next.js settings. In the Vercel project settings, add `tiarexine.com` and follow the DNS records Vercel provides at your domain registrar.
